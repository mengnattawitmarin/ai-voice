# AI Voice — Text to Speech · Voice Clone · Text to Image

เว็บแอป (PWA) ที่เปิดในมือถือได้ทันที และติดตั้งลงหน้าจอได้เหมือนแอปทั่วไป ไม่ต้องมีเซิร์ฟเวอร์ ทุกอย่างทำงานในเบราว์เซอร์ และใช้บริการ AI ที่มีแบบฟรี

## ฟีเจอร์

| หมวด | ทำได้ |
|---|---|
| แปลงข้อความเป็นเสียง | อ่านข้อความยาวไม่จำกัด (แบ่งช่วงอัตโนมัติ), ไฮไลต์ประโยคที่กำลังอ่าน, แตะประโยคเพื่อข้าม, ปรับความเร็ว/ระดับเสียง/โทน/รูปแบบการอ่าน, 13 ภาษา |
| แหล่งข้อความ | พิมพ์เอง, พูดเพื่อพิมพ์ (ไมค์), ไฟล์ .txt .pdf .docx .srt, **รูปถ่ายหน้าหนังสือ (OCR ไทย/อังกฤษ)**, ลิงก์บทความ |
| เสียง | เสียงในเครื่อง (ฟรี/ออฟไลน์), **เสียง AI ไทยฟรีที่ประมวลผลในมือถือ (MMS/VITS ผ่าน transformers.js ไม่ต้องใช้คีย์)**, เสียง AI 6 แบบผ่าน Pollinations, เสียงโคลนผ่าน F5-TTS บน Hugging Face |
| ส่งออก | ดาวน์โหลด MP3/WAV, แชร์ไฟล์เสียงไปแอปอื่น (เฉพาะเสียง AI/โคลน) |
| โคลนเสียง | อัดเสียง 6–15 วินาทีในแอปหรืออัปโหลดไฟล์ → ใช้เป็นเสียงอ่านข้อความ (ต้องติ๊กยืนยันว่าเป็นเสียงตัวเองหรือได้รับอนุญาต) |
| ข้อความเป็นรูปภาพ | **FLUX.1-schnell บน Hugging Face (ฟรี ไม่มีลายน้ำ)** หรือ Pollinations, 8 สไตล์, 4 สัดส่วน, 1–4 ภาพ, ขัดเกลาคำสั่งอัตโนมัติ, ดาวน์โหลด/แชร์/วาดใหม่ |
| อื่น ๆ | ประวัติการใช้งาน, ปุ่มควบคุมบนหน้าจอล็อก (Media Session), ใช้งานออฟไลน์ได้บางส่วน |

## บริการฟรีที่ใช้ และคีย์ที่ต้องมี

| บริการ | ใช้ทำอะไร | ต้องมีคีย์ไหม |
|---|---|---|
| Web Speech API ของเครื่อง | เสียงในเครื่อง, พูดเพื่อพิมพ์ | ไม่ต้อง |
| transformers.js + โมเดล MMS ไทย (Hugging Face) | เสียง AI ฟรีในเครื่อง | ไม่ต้อง (โหลดโมเดล ~110MB ครั้งแรก) |
| [Pollinations](https://enter.pollinations.ai) | เสียง AI, สร้างภาพ | ภาพ: ไม่ต้อง (ช้ากว่า 1 ภาพ/15 วิ) · เสียง AI: ต้องใช้ **Publishable key `pk_`** และต้องมี Pollen (บัญชีใหม่อาจมี 0 ต้องซื้อหรือทำ Quests) |
| [Hugging Face Spaces](https://huggingface.co/spaces) | โคลนเสียง (F5-TTS) | ไม่บังคับ — ใส่ HF token (Read) เพื่อได้โควตา GPU เพิ่ม |
| r.jina.ai | ดึงบทความจากลิงก์ | ไม่ต้อง |

คีย์ใส่ที่ **เมนู › ตั้งค่า & คีย์ API** และเก็บอยู่ในเครื่องนั้นเท่านั้น (localStorage)

## ข้อจำกัด

- เสียงในเครื่องบันทึกเป็นไฟล์ไม่ได้ (เบราว์เซอร์ไม่อนุญาต) คุณภาพขึ้นกับมือถือแต่ละรุ่น
- เสียง AI ของ Pollinations อ่านภาษาไทยได้ แต่สำเนียงยังไม่เหมือนคนไทย 100% เครดิตฟรีมีจำกัด
- โคลนเสียงใช้ GPU ฟรีของ Hugging Face: ต้องรอคิว, โควตาจำกัด, Space อาจหลับหรือถูกปิดได้ (เปลี่ยน Space ได้ในตั้งค่า), ข้อความยาวใช้เวลานาน, คุณภาพภาษาไทยยังไม่สมบูรณ์
- สร้างภาพแบบไม่มีคีย์อาจมีลายน้ำ และเข้าใจคำสั่งภาษาไทยได้น้อยกว่าอังกฤษ
- ไม่มีระบบสมาชิก/จ่ายเงินจริง ปุ่ม “อัปเกรดโปร” คือหน้าใส่คีย์ฟรี
- ข้อมูล (ประวัติ, เสียงโคลน) อยู่ในเครื่องนั้น ไม่ซิงก์ข้ามอุปกรณ์
- การเล่นต่อตอนล็อกจอไม่เสถียร โดยเฉพาะบน iPhone

## การใช้เสียงโคลนอย่างรับผิดชอบ

ใช้ได้เฉพาะเสียงของตัวเอง หรือเสียงที่เจ้าของอนุญาตแล้วเท่านั้น ห้ามใช้ปลอมเป็นผู้อื่น หลอกลวง หรือทำให้เข้าใจผิด
